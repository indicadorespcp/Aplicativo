  • Coluna Situação: retorna dados apenas para as siglas PA e PE.
  • Coluna 7 Itensped.Descrição do item: não retorna dados para registros que contenham “Elevador Social”.

  • Coluna "Diferença % Orçado vs Realizado":
    • Como foi criada: 
      Diferença Percentual = 
    se [Valor Total Orçado] <> nulo
       e [Valor Total Orçado] <> 0
       e [7 Itensped.Vlr total do item] <> nulo
    então
        ( [7 Itensped.Vlr total do item]
          - [Valor Total Orçado] )
        / [Valor Total Orçado]
    senão
        nulo
    • O que isso faz:
      • Subtrai o valor orçado do valor realizado
      • Divide pelo valor orçado
      • Retorna um percentual em formato decimal
    • Filtro aplicado (±50%): 
      [#"Diferença % Orçado vs Realizado"] >= -0.5
e [#"Diferença % Orçado vs Realizado"] <= 0.5
