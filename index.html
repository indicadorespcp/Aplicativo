Informações do Projeto

Tudo funciona em serviços gratuitos e seus dados estão seguros!

✅ Authentication (Login por Email/Senha)

  • Login por email/senha 100% gratuito
  • Sem custo por usuários
  • Sem limite de quantidade de contas

✅ Cloud Firestore (Banco de Dados)

O plano gratuito oferece:

  • 50.000 leituras por dia
  • 20.000 gravações por dia
  • 20.000 exclusões por dia
  • 1 GiB de armazenamento total

Limites técnicos:

  • Até 50.000 documentos por coleção
  • Até 100 campos por documento
  • Sem limite de coleções

Uso atual do projeto: apenas 2 coleção e poucos documentos, muito abaixo do limite.

✅ GitHub Pages (Hospedagem)

  • Hospedagem 100% gratuita
  • Certificado HTTPS gratuito
  • Tráfego gratuito
  • Sem limite de páginas

🔒 Segurança dos Dados

Todos os dados sensíveis estão protegidos usando os recursos do Firebase, incluindo:

  • Autenticação segura por email/senha
  • Regras de acesso no Firestore para que apenas usuários autorizados vejam/adicionem dados
  • Conexão criptografada (HTTPS) entre cliente e servidor

📌 Resumo

Todos os serviços utilizados no projeto são 100% gratuitos dentro do uso atual. Não haverá cobranças enquanto:

  • Não for ativado o plano Blaze (pago)
  • Não usar serviços pagos como Functions, Hosting avançado ou Storage grande
